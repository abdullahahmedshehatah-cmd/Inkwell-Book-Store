# 📚 Inkwell-Book-Store

Inkwell is a simple and responsive online bookstore built using **HTML, CSS, and JavaScript**.

The project provides a clean interface where users can explore books, view detailed information, and manage their shopping cart.

## ✨ Features

- Browse a collection of books.
- Filter books by category.
- View detailed book information.
- Add books to the shopping cart.
- Increase or decrease book quantities.
- Remove individual books or clear the cart.
- Automatically calculate the total price.
- Save cart data using LocalStorage.
- Responsive user interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser LocalStorage

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation is required.

## 📌 Note

This is a front-end demonstration project. The checkout process is simulated, and no real payments or backend operations are performed.
